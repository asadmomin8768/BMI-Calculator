# BMI Calculator

A simple and responsive **BMI Calculator** that calculates Body Mass Index based on height and weight.

## ✨ Features

* Calculate BMI instantly
* Accepts height and weight input
* Displays BMI result
* Shows BMI category
* Simple and responsive interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **JavaScript calculations, user input handling, and DOM manipulation**.
